# Implementation plan

## Milestone 1 — private repository and foundation

- Verify GitHub identity, create/verify private `cadmieldubic/doodlesteps`, initialize `main`, configure `origin`.
- Add secret-safe ignores, configuration template, engineering conventions, architecture, API contract, and progress records.
- Acceptance: privacy and remote verified; ignore checks pass; initial commit pushed and remote hash confirmed.

## Milestone 2 — drawing engine and demo tutor

- Implement strict backend scene validation and matching frontend runtime schemas.
- Author attractive puppy, flower, and house lessons with 4–6 consistent groups.
- Build responsive welcome, Finished Sketch, Step-by-Step Guide, per-line reveal, navigation, completion, restart, and printer worksheet.
- Acceptance: backend and frontend tests, typecheck, lint, production build, browser navigation/print checks, and visual review pass.

## Milestone 3 — photo and live AI integration

- Upload/camera selection, preview/replace/remove, format/size/content checks, metadata-free re-encoding.
- Two-stage configurable vision analysis and structured blueprint generation; reject unsuitable photos or invalid responses.
- Add rate/timeout/concurrency controls and safe errors. Preserve no-key demo experience without substituting demo output for uploaded photos.
- Complete integration and failure tests, documentation, ten-photo evaluation checklist, and desktop/mobile review.
- Acceptance: automated checks and mocked AI integration pass; live AI visual evaluation reported honestly if credentials are unavailable.

## Required product behavior

Warm cream workbook design; lavender/peach/mint/yellow accents; rounded typography; touch controls; reduced-motion support. Drawing primitives: lines, polylines, ellipses, polygons, smooth cubic Bézier paths; numeric coordinates, restrained palette, width/opacity, bounded complexity. Every step uses the same blueprint. Print includes a final sketch plus progressive steps and instructions.

## Deferred release work

No deployment. Before a children's-product release: parental consent, child-safety/content review, privacy and data-retention assessment, accessibility audit, abuse prevention, and broader visual-quality evaluation. These are release requirements, not claimed compliance.
